This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

sleek is an Electron + React + TypeScript desktop todo.txt manager (Linux/Windows/macOS). Requires Node >= 26. ESM (`"type": "module"`), built with electron-vite.

## Commands

- `npm run dev` — electron-vite dev with watch
- `npm run build` — regenerates the filter parser (`peggy`) then builds; `npm start` previews the build
- `npm test` — vitest (watch); `npx vitest run src/main/Foo.test.ts` for a single file; `npx vitest run -t "name"` for a single test; `npm run coverage`
- `npm run test:e2e` — builds, then Playwright (`src/e2e`, excluded from vitest)
- `npm run lint`, `npm run format` (check) / `npm run format:write`, `npm run typecheck` (node + web tsconfigs)
- Before a PR, CONTRIBUTING.md expects tests, format, lint and typecheck to pass. Test files sit beside sources as `Module.test.ts`.

## Architecture

Three Electron layers; the renderer never touches the filesystem directly.

- **`src/main`** — all todo.txt logic and state. `index.ts` boots the app; `IpcHandlers.ts`/`IpcMain.ts` register IPC handlers; `Stores.ts` holds `electron-store` stores (settings, filters, notified todos) and the colors from `resources/colors.json`.
  - `File/` — active file tracking, read/write, chokidar `Watcher` (external edits trigger re-render), archiving to done.txt.
  - `DataRequest/` — the core pipeline. `dataRequest()` in `DataRequest.ts` reads the file, builds todo objects (`CreateTodoObjects`, via `jstodotxt`; `linesInFile` is shared module state that attribute rename/delete mutates and writes back), applies search and filters (`Filters/`), then sorts (`Sort`) and groups (`Group`) and returns `RequestedData` (headers, attributes, grouped objects) to the renderer. Recurrence, completion, and priority restore are separate modules here.
  - `Filters/` — filter query language defined in `FilterLang.pegjs`. **`FilterLang.ts`/`.d.ts` are generated by peggy (gitignored) — edit the `.pegjs` and run `npm run peggy`**, never the generated file.
- **`src/preload/index.ts`** — `contextBridge` exposes `window.api` (typed in `electron.d.ts`); a mix of `sendSync` store getters and `send` calls.
- **`src/renderer`** — React 19 + MUI 9 UI (SCSS alongside). `IpcRenderer.tsx` receives `responseFromMainProcess`-style messages from main and feeds app state (`hooks/useAppState.ts`); feature folders: `Grid`, `Drawer`, `Header`, `Dialog`, `Settings`, `Picker`.
- **Shared types** are imported via the `@sleek-types` alias (`src/types`). Translations live in `src/locales` (i18next, configured in `src/i18n.config.ts` and `src/main/i18n.ts`).

Data flow: renderer action → preload `window.api` → IPC handler in main → mutate/write todo file → main re-runs `dataRequest` → reply to renderer with fresh data.

Packaging configs: `electron-builder.yml`, `flatpak/`, `snap/`, `build/`. Commit style: imperative subject, ≤50 chars, reference issues (e.g. "Fixes #123").
